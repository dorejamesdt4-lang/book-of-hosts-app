# Run and test

Requires Node.js 22 or later. No npm dependencies are required.

    npm test
    npm run build
    npm start

Open http://localhost:3000. On a phone, use the computer's LAN address and port 3000 while connected to the same network.

Check All, Games and Tools; open Membership to see Emerald and Sapphire with no payment actions. Toggle Magic calm and reload. Open Ruby, build and download a prompt, then paste a generated JSON response to check its basic structure and download it. Open the Manor and confirm the actual 3D bundle loads. Open Living Script's sample and use same-browser tabs for the host console and player hands. Showbox should offer captions when its sample audio is missing.

Imported tools retain old internal styling for now. External voice model downloads and fonts need internet. Legacy cloud-saving endpoints are absent and must not be treated as enabled. The new dashboard has no remote write operations. Full phone performance, AI output consistency, multiplayer and every legacy tool workflow require follow-up testing.

JSON workflows: use Load sample JSON in Mystery Box and Game Jester. In Mystery Box, advance through the acts; the final solution appears as a collapsed host-only section in the last act. In Jester, save the sample to Mini Games, open Mini Games and confirm the rules appear. Download a game and import its JSON again. Adult mini-games require the explicit audience confirmation before preview. Clearing browser storage removes the local library; downloaded JSON can be imported again. These workflows have automated contract tests; browser interaction verification is still required.

Complete Mystery Kit: after importing Ruby JSON, download each individual character/invitation PDF, the whole story (host only), narrator script, rules and keepsake. Download Complete Kit ZIP includes these PDFs plus game.json and showbox/manifest.json. Narrator PLAY/STOP cues are separate from spoken script. Optional narration_cues are preserved; older games receive clearly worded default host cues. Showbox is captions-only preparation with no audio files. Invitation details are used for exports and are not added to the AI prompt. Browser PDF/ZIP exports load pinned pdf-lib/JSZip from jsDelivr on demand.
